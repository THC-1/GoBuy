# GoBuy 商城前端设计规范 (Spec)

## 为什么 (Why)
本项目需要基于《第一版主要功能》文档完成 Spring Boot 3 + Vue 3 商城项目的前端页面。目标是打造一个响应式、视觉惊艳且自然的交互界面，提供极佳的 B 端管理员与 C 端用户体验。同时，遵循用户对“美观自然”的美学要求，坚决不使用任何紫色渐变。

## 做了哪些更改 (What Changes)
- 搭建基础 UI 组件库与样式引擎（例如使用 Tailwind CSS + Element Plus/Vant 或自定义精美组件）。
- 定义全局 CSS 变量，确立“自然、优雅、清新”的色彩基调（例如：大地色系、莫兰迪色或清爽的单色调配合低饱和度辅色）。
- 实现后台管理系统 (Admin Dashboard) 页面：
  - 管理员登录界面
  - 权限与系统基础（用户、角色、菜单、数据字典管理）
  - 商品中心（分类树、属性模板、SPU、SKU 录入与上下架）
  - 订单流转状态管理
- 实现 C 端用户商城 (C-End Mall) 页面：
  - 首页及商品展示
  - 商品详情页（多规格 SKU 选择、商品评价展示）
  - 用户模块（注册/登录、个人信息维护、收货地址、收藏夹）
  - 购物车与订单流转（加购、结算、确认订单、模拟支付界面）

## 影响 (Impact)
- 影响的功能：前台商城与后台管理系统的 UI/UX、路由跳转、状态管理 (Pinia)。
- 影响的代码：`frontend` 目录下的所有相关目录与文件。

## 新增需求 (ADDED Requirements)
### 需求：前端美学与设计方向
系统必须采用自然、简洁、优雅的设计语言。
- **排版 (Typography)**：采用干净无衬线字体，标题和正文形成良好的阅读层次。
- **色彩 (Colors)**：采用自然的大地色系或简约的清爽色系，**严禁使用紫色渐变**。
- **布局 (Layout)**：留白充裕，利用微小的阴影和圆角营造呼吸感和高级感，杜绝刻板的“AI 审美”。
- **动效 (Motion)**：关键交互处（如加入购物车、页面切换）加入丝滑的过渡动画。

### 需求：后台管理系统界面
系统需提供给运营和管理员操作的管理控制台界面，重点在于数据表单、表格和复杂的 SKU 动态生成组件的交互。

### 需求：C端商城界面
系统需提供给普通消费者的浏览和购买界面，要求页面加载流畅，商品展示吸引人，购物流程无缝衔接。
