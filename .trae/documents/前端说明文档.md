# GoBuy 前端说明文档

## 一、项目概述

GoBuy 前端是一个基于 Vue 3 的电商系统前端应用，采用前后端分离架构，包含商城前台和管理后台两个子系统。

### 技术栈

- **核心框架**: Vue 3.5.31
- **构建工具**: Vite 8.0.3
- **状态管理**: Pinia 3.0.4
- **路由**: Vue Router 5.0.4
- **UI 组件库**: Element Plus 2.13.6
- **样式**: Tailwind CSS 4.2.2
- **语言**: TypeScript 6.0.0
- **代码规范**: ESLint 10.1.0 + Prettier 3.8.1
- **测试**: Vitest 4.1.2 + Vue Test Utils 2.4.6

## 六、API 请求规范

### 6.1 后端接口地址

开发环境默认后端地址：`http://localhost:8080`

### 6.2 统一响应格式

后端返回的数据格式：

```typescript
interface Result<T> {
  code: number
  message: string
  data: T
  timestamp: string
```

### 6.3 认证方式

使用 JWT Token 进行认证：

- 登录后获取 Token
- 将 Token 存储在本地（localStorage/sessionStorage）
- 在请求头中携带：`Authorization: Bearer <token>`

## 八、组件开发规范

### 8.1 单文件组件结构

```vue
<script setup lang="ts">
// 导入
import { ref, computed } from 'vue'
import type { PropType } from 'vue'

// Props 定义
const props = defineProps<{
  title: string
  count?: number
}>()

// Emits 定义
const emit = defineEmits<{
  (e: 'update', value: string): void
}>()

// 响应式数据
const localData = ref('')

// 计算属性
const computedValue = computed(() => {
  return props.count * 2
})

// 方法
const handleClick = () => {
  emit('update', localData.value)
}
</script>

<template>
  <div class="component-class">
    <!-- 模板内容 -->
  </div>
</template>

<style scoped>
/* 样式 */
</style>
```

### 8.2 命名规范

- **组件文件**: 大驼峰命名，如 `UserProfile.vue`
- **组件名称**: 与文件名一致
- **变量**: 小驼峰命名
- **常量**: 全大写下划线分隔
- **类型**: 大驼峰命名，接口以 `I` 开头或使用 `Type` 后缀

### 8.3 组件通信

#### Props
父组件向子组件传递数据

#### Emits
子组件向父组件发送事件

#### Provide/Inject
跨层级组件通信

#### Pinia Store
全局状态管理

## 九、状态管理 (Pinia)

### 9.1 Store 定义

```typescript
// src/stores/counter.ts
import { defineStore } from 'pinia'

export const useCounterStore = defineStore('counter', {
  state: () => ({
    count: 0,
  }),
  getters: {
    doubleCount: (state) => state.count * 2,
  },
  actions: {
    increment() {
      this.count++
    },
  },
})
```

### 9.2 在组件中使用

```typescript
<script setup lang="ts">
import { useCounterStore } from '@/stores/counter'

const counterStore = useCounterStore()

// 访问 state
console.log(counterStore.count)

// 调用 action
counterStore.increment()

// 访问 getter
console.log(counterStore.doubleCount)
</script>
```

## 十、路由守卫

### 10.1 认证守卫

需要在路由配置中添加守卫验证用户登录状态：

```typescript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  
  // 需要认证的路由
  if (to.path.startsWith('/admin') && !token) {
    next('/admin/login')
  } else if (to.path.startsWith('/user') && !token) {
    next('/login')
  } else {
    next()
  }
})
```

### 10.2 权限守卫

根据用户角色和权限控制路由访问：

```typescript
// 检查用户是否有访问该路由的权限
const hasPermission = user.permissions.includes(route.meta.permission)
```
