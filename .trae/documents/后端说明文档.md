# GoBuy 后端说明文档

## 一、项目概述

GoBuy 后端是一个基于 Spring Boot 3 的电商系统后端服务，采用前后端分离架构，提供完整的电商功能 API 接口。

### 技术栈

- **核心框架**: Spring Boot 3.5.13
- **安全框架**: Spring Security 6 + JWT (jjwt 0.12.7)
- **ORM 框架**: MyBatis-Plus 3.5.12
- **数据库**: MySQL 8.0
- **构建工具**: Maven
- **Java 版本**: Java 17
- **其他**: Lombok, H2 (测试用)

## 三、核心功能模块

### 3.1 认证模块 (Auth)

**接口路径**: `/api/**`

#### 管理员登录
- `POST /api/admin/login` - 管理员登录
- `GET /api/admin/me` - 获取当前管理员信息（需权限：`dashboard:view`）

#### 商城用户
- `POST /api/user/register` - 用户注册
- `POST /api/user/login` - 用户登录
- `GET /api/user/me` - 获取当前用户信息（需权限：`mall:profile:view`）

### 3.2 系统管理模块 (System)

**接口路径**: `/api/admin/system/**`

#### 用户管理
- `GET /api/admin/system/users` - 分页查询用户
- `POST /api/admin/system/users` - 创建用户
- `PUT /api/admin/system/users/{id}` - 更新用户
- `PATCH /api/admin/system/users/{id}/status` - 更新用户状态
- `DELETE /api/admin/system/users/{id}` - 删除用户

#### 角色管理
- `GET /api/admin/system/roles` - 分页查询角色
- `GET /api/admin/system/roles/options` - 角色选项列表
- `POST /api/admin/system/roles` - 创建角色
- `PUT /api/admin/system/roles/{id}` - 更新角色
- `DELETE /api/admin/system/roles/{id}` - 删除角色

#### 菜单权限
- `GET /api/admin/system/menus/tree` - 菜单树
- `POST /api/admin/system/menus` - 创建菜单
- `PUT /api/admin/system/menus/{id}` - 更新菜单
- `DELETE /api/admin/system/menus/{id}` - 删除菜单

#### 数据字典
- `GET /api/admin/system/dicts` - 字典类型分页
- `GET /api/admin/system/dicts/{dictType}/items` - 字典项列表
- `POST /api/admin/system/dicts` - 创建字典类型
- `PUT /api/admin/system/dicts/{id}` - 更新字典类型
- `DELETE /api/admin/system/dicts/{id}` - 删除字典类型
- `POST /api/admin/system/dict-items` - 创建字典项
- `PUT /api/admin/system/dict-items/{id}` - 更新字典项
- `DELETE /api/admin/system/dict-items/{id}` - 删除字典项

### 3.3 商品模块 (Product)

**接口路径**: 
- 管理端：`/api/admin/product/**`
- 客户端：`/api/products/**`

#### 商品分类
- `GET /api/admin/product/categories/tree` - 分类树
- `POST /api/admin/product/categories` - 创建分类
- `PUT /api/admin/product/categories/{id}` - 更新分类
- `DELETE /api/admin/product/categories/{id}` - 删除分类

#### 属性模板
- `GET /api/admin/product/attribute-templates` - 模板分页
- `GET /api/admin/product/attribute-templates/{id}` - 模板详情
- `POST /api/admin/product/attribute-templates` - 创建模板
- `PUT /api/admin/product/attribute-templates/{id}` - 更新模板
- `DELETE /api/admin/product/attribute-templates/{id}` - 删除模板

#### SPU/SKU 管理
- `GET /api/admin/product/spus` - SPU 分页
- `GET /api/admin/product/spus/{id}` - SPU 详情
- `POST /api/admin/product/spus` - 创建 SPU
- `PUT /api/admin/product/spus/{id}` - 更新 SPU
- `PATCH /api/admin/product/spus/{id}/status` - 更新 SPU 状态
- `DELETE /api/admin/product/spus/{id}` - 删除 SPU

#### 客户端接口
- `GET /api/products/recommend` - 推荐商品列表
- `GET /api/products/{id}` - 商品详情

### 3.4 购物车模块 (Cart)

**接口路径**: `/api/cart/**`

- `GET /api/cart/items` - 购物车列表
- `POST /api/cart/items` - 添加商品到购物车
- `PUT /api/cart/items/{id}` - 更新购物车商品数量

### 3.5 订单模块 (Order)

- `POST /api/user/center/addresses` - 新增收货地址

- `DELETE /api/user/center/addresses/{id}` - 删除收货地址

## 五、安全配置

### 5.1 JWT 认证

- **Token 生成**: 使用 `JwtTokenProvider` 生成 JWT Token
- **Token 验证**: 通过 `JwtAuthenticationFilter` 拦截请求验证 Token
- **Token 有效期**:
  - 管理员：720 分钟（12 小时）
  - 商城用户：10080 分钟（7 天）

### 5.2 权限控制

#### 接口权限规则
```java
// 公开接口
/api/admin/login - 允许所有人
/api/user/login, /api/user/register - 允许所有人

// 管理员权限
/api/admin/** - 需要 ROLE_ADMIN 角色

// 商城用户权限
/api/user/** - 需要 ROLE_MEMBER 角色
/api/cart/**, /api/orders/** - 需要 ROLE_MEMBER 角色
```

#### 权限码（Permission Code）
- `dashboard:view` - 查看仪表盘
- `mall:profile:view` - 查看用户资料

### 5.3 密码加密

使用 BCrypt 密码编码器进行密码加密存储。

### 5.4 CORS 配置

允许的前端地址：
- `http://localhost:5173`
- `http://127.0.0.1:5173`

允许的 HTTP 方法：GET, POST, PUT, DELETE, PATCH, OPTIONS

## 八、启动说明

### 8.1 前置要求

1. Java 17+

### 8.2 启动步骤

1. **创建数据库并执行脚本**
```bash
mysql -u root -p < sql/01_schema.sql
```

3. **启动项目**

或打包后运行：
```bash
./mvnw clean package
java -jar target/backend-0.0.1-SNAPSHOT.jar
```

## 十、开发规范

### 10.1 代码规范

- 使用 Lombok 简化实体类代码
- Controller 层统一使用 `Result` 封装返回结果
- Service 层处理业务逻辑
- 使用 MyBatis-Plus 的 Mapper 进行数据访问

### 10.2 异常处理

使用 `GlobalExceptionHandler` 统一处理异常：
- `BusinessException` - 业务异常
- 其他未捕获异常统一返回服务器错误

### 10.3 日志规范

- 开发环境开启 SQL 日志输出
- 生产环境建议调整为 ERROR 级别

## 十一、常见问题

### 11.1 数据库连接失败

检查 MySQL 服务是否启动，数据库连接配置是否正确。

### 11.2 JWT Token 失效

检查 JWT 密钥配置，确保前后端使用相同的密钥。

### 11.3 CORS 跨域问题

检查前端请求地址是否在允许的 Origin 列表中。
