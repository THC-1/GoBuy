git clone https://github.com/THC-1/GoBuy.git

# 切换到 dev 分支
git checkout dev
# 拉取远程 dev 的最新代码
git pull origin dev

# 创建并切换到新分支 feature-login
git checkout -b feature-login

# 将所有改动添加到暂存区
git add .
# 提交改动并写好备注
git commit -m "feat: 完成用户登录接口"

# 将本地的 feature-login 分支推送到远程仓库
git push -u origin feature-login


5. 发 PR（Pull Request：feature → dev）
这一步不需要敲命令，是在 GitHub 网页端完成的。
登录 GitHub 的 GoBuy 仓库页面。
页面顶部会提示你刚刚推送了一个分支，旁边会有一个绿色的按钮 "Compare & pull request"，点击它。
确保合并方向是：base: dev  <--  compare: feature-login。
填写一下你完成了什么功能，点击 "Create pull request"。
(团队合作中，这个时候通常会叫同学来 Code Review（代码审查），互相看看代码有没有问题)
6. 合并到 dev
这也是在 GitHub 网页端完成的。
PR 审核没问题后，点击页面上的绿色按钮 "Merge pull request"。
确认合并后，你的 feature-login 代码就进入远程的 dev 分支了。
合并完后，你可以在网页上把这个完成使命的 feature-login 分支删掉。
【关键善后】： 远程 dev 更新了，你本地的 dev 还是旧的，记得切回去更新一下：
git checkout dev
git pull origin dev
7. 项目阶段完成 → dev → main
当你们完成了一个大阶段（比如第一版系统终于做完了，要交给老师验收），就把开发环境的 dev 合并到生产环境的 main。
还是在 GitHub 网页端操作：
重新建一个 Pull Request。
设置合并方向：base: main  <--  compare: dev。
创建 PR 并点击 Merge 合并。这样你们的 main 分支就有了第一个稳定版本的代码！
